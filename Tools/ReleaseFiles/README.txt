===============================================================================
 CyGameCapture @VERSION@ - GPU capture toolkit for Windows
===============================================================================

Pick any render target of a game's frame - for example the clean scene before
the interface is drawn - and stream it over Spout2, entirely on the GPU. OBS,
Resolume, TouchDesigner, another Unreal instance or any Spout2 application can
receive it.

What is in this package
-------------------------------------------------------------------------------

  ReShade-Addon\      the ReShade add-on (CyGameCaptureRS.addon64) and the
                      helper of its AI assistant (CyGameCaptureAI.exe).
                      Start with README.txt in that folder.
  OBS-Plugin\         the OBS Studio plugin: Install-OBS-Plugin.cmd.
  Unreal-Plugin\      the Unreal Engine plugin, one folder per engine version:
                      copy CyGameCaptureUE into <YourProject>\Plugins.
  Documentation\      the project's README, the changes of this version, the
                      architecture document and the READMEs of each plugin.
  LICENSE.txt         GNU Affero General Public License v3.

 CyGameCapture @VERSION@ - boite a outils de capture GPU pour Windows
===============================================================================

Choisissez n'importe quelle cible de rendu d'une image de jeu - par exemple la
scene propre avant que l'interface soit dessinee - et envoyez-la en Spout2,
entierement sur le GPU. OBS, Resolume, TouchDesigner, une autre instance
d'Unreal ou toute application Spout2 peut la recevoir.
